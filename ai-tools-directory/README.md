# AI Tools Directory (Arabic MVP)

MVP لواجهة Next.js + Tailwind مع صفحات رئيسية: الرئيسية، الفئات، تفاصيل الأداة، البحث، وإضافة أداة.

## التشغيل محليًا
1) Node.js 18+
2) `npm install`
3) `npm run dev`

> قاعدة البيانات وطبقة البيانات ستضاف في خطوة لاحقة وفق المخطط المرفق.

## Internationalization (i18n)
This build ships with bilingual routing:
- Arabic under /ar
- English under /en

See README_I18N.md for details (dictionaries, SEO per locale, sitemaps, JSON-LD, hreflang).
